通知欄：自動
常用
說明｜Help
  • BPM：速度。輸入 10–1000。｜Tempo. Enter 10–1000.
  • Start / Stop：同一鍵切換播放與停止。｜One button toggles play and stop.
  • Tap：連點抓速度。｜Tap repeatedly to set BPM.
  • Gain：總響度。太刺耳就降低。｜Master loudness. Lower it if harsh.
  • Track：四軌同步疊加，不是四拍循環。｜Four tracks play stacked, not as four beats.
  • Split：輸入 0–1 的拍內位置。空白＝不播放。｜Enter positions from 0–1. Blank = silent.
  • 例：0＝主拍；0,0.5＝兩下；0,0.25,0.5,0.75＝四下。｜Examples: 0 = downbeat; 0,0.5 = two hits; 0,0.25,0.5,0.75 = four hits.
  • ON：開關該軌。｜Enable or mute the track.
  • Vol：該軌音量。｜Track volume.
  • MIDI / Hz：音高。改 MIDI 會換算 Hz；改 Hz 會回推 MIDI。｜Pitch. MIDI and Hz update each other.
  • Len：聲音長度，ms。｜Click length in milliseconds.
  • Wave：波形音色。｜Waveform tone color.
  • Param：展開軌道音量、音高、長度與波形。｜Open track volume, pitch, length, and waveform.
  • Play：試聽該軌；改參數會立即回饋。｜Preview the track; edits give instant feedback.
  • 通知欄：預設啟用，可播放、暫停、停止。｜Media controls are on by default: play, pause, stop.

手機建議用 Chrome / Safari；通知欄顯示依瀏覽器支援而定。｜Use Chrome / Safari on mobile; notification controls depend on browser support.
