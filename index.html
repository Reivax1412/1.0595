About 1.0595

1.0595 is derived from the approximate frequency ratio of one semitone in twelve-tone equal temperament. The interface uses a deep-navy visual system for stability and control, with muted steel blue reserved for focus, timing, and active states.

Getting Started

Set BPM, choose a Track, and use the 4×4 pads as sixteen independent Event slots. A bright pad plays; a dark pad does not. Select a pad, set its Beat, Split, and Point in the Event inspector, then press START.

  1. Set BPM.
  2. Select a Track.
  3. In STEP mode, tap or swipe to edit Events.
  4. Long-press an Event to open Event Edit.
  5. Choose Meter, Beat, Split, and Point as needed.
  6. Press START. PAUSE preserves the musical position; STOP returns to the bar start.

Gestures

STEP uses one consistent gesture model on pointer-capable devices: tap toggles one Event, swipe paints or erases multiple Events, and a stationary 500 ms long-press opens that Event for detailed editing. Swipe direction does not toggle repeatedly: the first Event decides whether that pointer paints ON or erases OFF. Multiple pointers are tracked independently.

Meter and Bar Structure

Each Pattern stores its own Bar Length and Beat Count. Presets include 2/4, 3/4, 4/4, and 6/8; Custom exposes the same two underlying values. Pattern changes still occur at a bar boundary. Editing bar structure while paused resets transport to Beat 1 because the old musical position may no longer exist.

Event and Split

Each pad is an Event, not a fixed sixteenth note. Beat chooses a beat within the current Pattern. Split divides that beat into equal parts. Point chooses which part receives the Event.

Tracks, Articulation, and Retrig

Each of the four Tracks stores its own Events and sound settings. ART changes how an active Event is played: Normal, Accent, Marcato, Staccato, or Tenuto. RETRIG repeats an Event two to four times inside its own Split interval.

Sound Settings

Each Track keeps independent Sound, Level, Pitch, Length, Brightness, and Noise. The main TRACK inspector exposes the frequent controls: Sound, Level, Pitch, Length, and Mute. Advanced sound controls—Brightness, Noise, Pitch Display, and Master Volume—are in ? → Sound.

All valid numeric edits are committed after 30 ms and update visible summaries immediately. Master Volume 100% maps to gain 1.00 while the Dynamics Compressor remains active.

Layout

Laptop/Desktop: the 4×4 sequencer stays on the left. The compact right inspector uses EVENT and TRACK tabs so the pad grid can remain large without forcing page scrolling. Low-frequency and advanced controls are kept in Settings.

Phone: the main screen shows the rhythm machine only. Open ? for Edit, Sound, Tools, Log, Guide, and Release Notes.
